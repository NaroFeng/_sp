# p0 語言規格書

## 1. 語言目標與功能

p0 是一個教學用程式語言，目標是：
- 結構簡單，易於學習編譯器原理
- 支援函數、條件判斷、迴圈等基本結構
- 編譯至基於堆疊的位元組碼，由虛擬機執行

## 2. 程式範例

### 階乘函數
```
func fact(n) {
    if (n < 2) {
        return 1;
    }
    return n * fact(n - 1);
}
```

### 質數判斷
```
func is_prime(n) {
    i = 2;
    while (i < n) {
        if (n - (n / i) * i == 0) {
            return 0;
        }
        i = i + 1;
    }
    return 1;
}
```
