# p0 語言編譯器

## 語言規格

- **強型態**: 整數 only
- **編譯/解譯**: 編譯至位元組碼，虛擬機執行
- **目標檔**: 基於堆疊的位元組碼 (Bytecode)
- **垃圾蒐集**: 否 (手動記憶體管理)

## 支援語法

- `func` 函數定義
- `if` 條件判斷
- `while` 迴圈
- 算術運算: `+`, `-`, `*`, `/`
- 比較運算: `==`, `<`, `>`
- `return` 回傳值
- 單行註解 `//` 與多行註解 `/* */`

## 編譯與執行

```bash
gcc -o compiler compiler.c && ./compiler <source.p0>
```

## 測試範例

- `p0/while_sum.p0` - 計算 1+2+...+10 = 55
- `p0/fact.p0` - 計算 5! = 120
- `p0/prime.p0` - 判斷 17 是否為質數
